# O·COMPLEX — концепт главной страницы

Демо для заказа FL.ru №5529020: редизайн главной o-complex.ru — фильтр для воды
WATER FILTER и пищевой цеолит из природного минерала.

Воздушный светлый дизайн, крупная типографика, сочные фото, тонкие линии вместо
тяжёлых теней. Чистый HTML + CSS + минимум JavaScript: ни фреймворков, ни сборки.

## Как открыть

Просто откройте `index.html` в браузере (двойной клик или `file://`). Сервер не нужен.

Быстрая проверка палитр без клика по переключателю: `index.html?theme=b`,
`index.html?theme=c`, `index.html?theme=a`.

## Файлы

```
demo/
├─ index.html          вся страница, 4 экрана, семантика и alt у фото
├─ assets/
│  ├─ style.css        токены, три палитры, сетка, адаптив 1120 / 860 / 560
│  ├─ app.js           темы + localStorage, бургер-меню, фильтр каталога, фолбэк фото
│  └─ img/             hero, product-filter, product-zeolite, product-powder,
│                      product-set, science, lifestyle (.jpg)
└─ README.md
```

Фото подключаются только из `assets/img/*.jpg` (внешних картинок нет). Пока файла
нет, контейнер держит `aspect-ratio`, показывает мягкую подложку — вёрстка
не «схлопывается».

## Переключатель стиля

Главная фишка: панель внизу слева (на мобильных — компактные чипы снизу).
Три палитры, все токены — CSS-переменные на `:root` и `[data-theme]` у `<html>`:

| Тема | Настроение | Фон | Чернила | Акцент | Мягкая подложка | Линия |
|---|---|---|---|---|---|---|
| **B** (по умолчанию) | Тёплый премиум | `#FCF6ED` | `#1F1B16` | `#C23B22` | `#CBCFB4` | `#E6DDD0` |
| **C** | Сочный DTC | `#FFF9F2` | `#101010` | `#FF4D2E` | `#1E4634` | `#EFE2D5` |
| **A** | Минеральный свет | `#F7F6F2` | `#16181D` | `#2D5BFF` | `#FF6B4A` | `#E4E3DD` |

Выбор сохраняется в `localStorage` (ключ `ocomplex.theme`), применяется до первой
отрисовки — без мигания чужой палитры. У каждой темы свои `--accent-ink`
(цвет текста на акценте), `--soft-bg` / `--soft-ink` (подложка и текст на ней),
`--hl-bg` для выделенной колонки таблицы — поэтому все три выглядят цельно,
а не как перекраска одного макета.

## Четыре экрана

1. **Hero** — шапка с логотипом `O·COMPLEX`, меню, корзина со счётчиком и пилл
   «Купить»; бейджи преимуществ, H1 в три строки (Prata, до 74 px) с акцентным
   курсивным «цеолит», подзаголовок, две кнопки, строка цифр-доказательств
   в 4 колонки с тонкими разделителями; справа фото в скруглённой рамке,
   плашка «181 отзыв · 4,8★», декоративные круг и кольцо мягкого цвета.
2. **Каталог** — надзаголовок, H2, лид справа, чипы-фильтры (работают), 4 карточки
   с бейджами, ценами и кнопками «В корзину»: WATER FILTER, пищевой цеолит,
   порошок, набор «Детокс 30 дней». На планшете 2 карточки, на мобильном 1.
3. **Наука + симптоматика** — панель на мягкой подложке со скруглением 32 px:
   H2 и объяснение минерала, фото, дисклеймер, 3 шага (сорбирует / обменивает /
   насыщает), 3 плитки симптоматики, таблица сравнения «Обычный фильтр» против
   «WATER FILTER + пищевой цеолит» с выделенной акцентом колонкой.
4. **Клуб + отзывы + сервис + футер** — фото lifestyle, три уровня клуба
   (Старт 5% / Серебро 10% / Золото 15%, средний выделен), 3 отзыва со звёздами,
   плашка рейтинга, полоса сервиса с тонкими SVG-иконками, футер с контактами,
   реквизитами, дисклеймером и плашкой «Концепт-демо для FL.ru №5529020».

## Технические решения

- Сетка: контейнер 1240 px, 12 колонок, вертикальный ритм кратен 8 px,
  секции 120 px (96 / 80 / 64 px на меньших экранах).
- Шрифты: Google Fonts **Prata** (display, 400) + **Golos Text** (400/500/600),
  подключение одним `<link>` с `preconnect`; fallback — Georgia и system-ui.
- Кнопки min-height 48 px, радиусы 100 px у пиллов, 20–24 px у карточек.
- Границы 1 px цветом линии, тени только мягкие `rgba(31,27,22,.07)`.
- Переходы 160–220 ms, видимая фокус-обводка, `prefers-reduced-motion`,
  skip-link, `aria-pressed` у чипов и переключателя, `aria-label` у иконок.
- Меню на мобильных — бургер с раскрывающейся панелью (Esc, клик по ссылке,
  resize закрывают меню).
- Фильтр каталога — `data-cat` у карточек, кнопки с `aria-pressed`.
- Без горизонтального скролла: декоративные круги обрезаются секцией,
  таблица на мобильном превращается в карточки с подписями `data-label`.

## Проверка

`aria-labelledby`, `aria-controls` и якоря существуют, у всех `<img>` есть `alt`,
неизвестных CSS-переменных нет, тексты ТЗ присутствуют дословно, нет lorem ipsum,
«TODO» и служебных заглушек.
